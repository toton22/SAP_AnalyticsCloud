Uploads

Everything in the repository's uploads/ folder, listed by itself. Add a file on GitHub or push one from your machine; the manifest rebuilds and this page follows. Screenshots open full size, notes open inline, documents download.

step 1

Drop the file in

On GitHub: uploads/ → Add file → Upload files. Or copy it locally and push. A folder named YYYY-MM-DD-what-it-was keeps a session together.

step 2

The Action rebuilds the index

A GitHub Action notices the push, runs scripts/build_manifest.py and commits uploads/manifest.js back. About a minute.

step 3

This page updates

GitHub Pages redeploys and the new file appears here, grouped by session. On github.io the page also checks the repository tree, so a file shows as pending even before the Action finishes.
